# 🏛️ SynapseGuild — Autonomous Multi-Agent RPG Guildhall

> **Visual Multi-Agent Autonomous Development Environment with 2.5D Pixel RPG Interface, Dialectical Consensus Engine, and Dual-Ingress (Web + Telegram Remote).**

---

## 🌟 Overview

**SynapseGuild** bridges autonomous AI multi-agent orchestration with the visual immersion of a retro RPG Guildhall. Three specialized AI agents—**The Architect** (*The Sage*), **The Craftsman** (*The Forge Master*), and **The Sentinel** (*The Grand Inquisitor*)—collaborate, write code, run automated sandbox tests, and debate in real-time to solve complex quests.

---

## ⚔️ The Party (Personas & Roles)

1. **👑 The Architect / Sage (Planning & Strategy):**
   * Decomposes user goals into actionable DAG specifications and BDD acceptance criteria.
   * Gathers in *The War Room* for strategic debates.

2. **🔨 The Craftsman / Forge Master (Implementation & Code):**
   * Writes modular code, executes tools in sandboxes, and implements fixes.
   * Works in *The Forge* with real-time terminal stream output.

3. **⚔️ The Sentinel / Grand Inquisitor (Auditing & Testing):**
   * Adversarial code auditor that executes `pytest`/unit tests in ephemeral sandboxes.
   * Inspects artifacts in *The Chamber of Judgment* with score-based pass/fail gates.

---

## 🎮 RPG Telemetry Mapping

* 🔴 **HP (Health Points):** Error tolerance & retry budget (deducts on failed tests).
* 🔵 **MP (Mana Points):** Reasoning token capacity & context window budget.
* 🛡️ **Armor / Defense:** Test coverage % and strict type-safety score.
* ⭐ **EXP & Leveling:** Completed quests count unlocking persistent agent skills.
* 🎒 **Loot Drops:** Downloadable verified code artifacts (.py, .ts, .zip).

---

## 📱 Dual-Ingress Workflow

* **🖥️ Web Quest Board (Next.js + Phaser.js 3):** Real-time 2.5D visual simulation with sprite pathfinding, speech bubbles, live terminal drawer, and time-travel replay bar.
* **📱 Dedicated Admin Telegram Bot:** Remote quest dispatcher (`/quest`, `/status`, `/loot`) with milestone push notifications and artifact document delivery.
